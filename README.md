# 💸 Expense Tracker

A simple and interactive **Expense Tracker App** built with **HTML**, **CSS**, and **JavaScript**.  
This app lets users add, view, and delete expenses while tracking the total — with all data stored in the browser using `localStorage`.

---

## 🔮 Features

- ➕ Add new expenses with name and amount
- 🗑️ Delete individual expenses
- 💰 Automatically updates total amount
- 💾 Data stored using `localStorage`
- 🔄 Expenses and total persist across page reloads
- 🎨 Clean and minimal UI

---

## 🖥️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- LocalStorage API
